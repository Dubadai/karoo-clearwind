# Settings: Example card

Agreed 2026-11-07 (option A, design in `karoo-starter/docs/design/settings-preview/`): an "Example"
card under the title shows the wind field as the settings make it (5.2 m/s, tailwind from the
left), drawn by `WindRenderer`, at a half-width one-row field's size. It updates on every tap and
stays put while the settings scroll.

Screenshots (Karoo 3 emulator, 480 × 800 at 300 dpi; emulator status bar):
`01-settings-example-light.png`, `02-settings-example-dark.png`, `03-settings-example-kmh-light.png` (after tapping km/h).
