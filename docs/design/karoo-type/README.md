# Header from KarooType

The Karoo's field typography now lives in one shared file, `KarooType.kt` (from karoo-starter;
notes in the workspace's `design-assets/karoo-type/`). ClearWind's header takes its cap height,
cap top and right inset from it. Visible change: in a full-width row under 150 px tall the header
sits 12 px from the top like the Karoo's own labels (it was 21). Other sizes move 1 px right.
The wind icon stays as it was.
