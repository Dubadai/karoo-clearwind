ClearWind: field mockup, round 5

The speed is now always centred in the field, left to right, in every size. Same colour tile, front dot (you) and thin arc to where the wind blows as round 4.

Examples: headwind 5 m/s (from 20° right), crosswind 3.3 m/s (from the left), quartering tailwind 4.2 m/s (from behind left), tailwind 6.1 m/s.

Layout A: arrow centred, speed centred under it

One column, everything centred. In short fields the arrow has to share the height with the number, so it gets smaller.

Layout B: speed in the centre of the dial

The number sits dead centre; the arrow becomes a big arrowhead on the dial edge, pointing where the wind blows, with the arc running to it from the front dot. The dial can use the full field height, so it stays big in short fields.
